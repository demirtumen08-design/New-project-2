# iOS Trading Analyzer

Bu klasor SwiftUI tabanli iOS uygulama iskeletini icerir.

## Ozellikler

- SwiftUI arayuzu
- Paper trading dashboard
- Strateji secimi
- Simulasyon ekranlari
- iPhone uyumlu tasarim

## Xcode ile Acma

1. Xcode ac
2. ios klasorunu import et
3. Yeni iOS App target olustur
4. SwiftUI sec
5. ContentView.swift dosyasini kullan

## Gelecek Surum

- Gercek zamanli grafikler
- TradingView entegrasyonu
- AI sinyal motoru
- Push notification
- FastAPI backend baglantisi
- WebSocket market feed
